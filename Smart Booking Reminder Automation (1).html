How it works

From confirmation email to calendar event

Booking details are scattered across inboxes. The script gathers them into one place without any manual copying.

1

Detect

A time-driven trigger scans Gmail every 15 minutes for new IRCTC and KSRTC confirmations.

2

Extract

Regex-based parsers read PNR, route, coach, seat and departure time from each email format.

3

Schedule

A Google Calendar event is created with a four-stage reminder pipeline, and the email is labelled to prevent duplicates.

Setup guide

Install it in about five minutes

It runs inside your own Google account. The snippets below are examples of the key parts; the complete script is in the GitHub repository.

1

Create the project

Open script.google.com, create a new project and paste in the script from the repository.

2

Find booking emails

Search only for confirmations that have not been processed yet.

from:(ticketadmin@irctc.co.in OR etickets@ksrtc.in) -label:processed
3

Add the four reminders

Reminder offsets are in minutes before departure.

[7200, 4320, 1440, 60].forEach(function (m) {
  event.addPopupReminder(m);
});
4

Start the 15-minute trigger

Run this once and approve the Gmail and Calendar permissions.

function setup() {
  ScriptApp.newTrigger('processBookings')
    .timeBased().everyMinutes(15).create();
}
Privacy

Your data stays in your account

The script runs under your own Google account. It reads only booking emails and writes only to your calendar.

No external server

There is no backend of ours. Nothing is sent anywhere except Google's own Gmail and Calendar services.

Narrow access

It looks only for IRCTC and KSRTC confirmations and marks them with a label so they are not read again.

Open source

The code is public on GitHub, so anyone can read exactly what it does before running it.

FAQ

Common questions

Does it cost anything?

No. It runs on Google Apps Script, which is free for personal use within Google's standard quotas.

Which tickets are supported?

IRCTC rail and KSRTC bus confirmations, whether they arrive directly, via Cloudflare email routing, or forwarded from Gmail.

How fast does an event appear?

The script checks every 15 minutes, so a new confirmation is usually on your calendar within that time.

Will it create duplicates?

No. Each processed email gets a Gmail label, and labelled emails are skipped on later runs.

What if an email format changes?

A parser may need a small update. Opening an issue on GitHub is the best way to report it.
