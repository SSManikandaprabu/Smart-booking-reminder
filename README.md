# Smart Booking Reminder Automation

A booking and appointment tracking dashboard with reminder scheduling, status tracking, and calendar export.

## Features

- Log appointments, meetings, and client reservations with date and time pickers
- Visual appointment status indicators (Upcoming, In-Progress, Completed, Overdue)
- Automated countdown timers highlighting imminent bookings
- Filter and search appointments by client, service type, or date range
- Export reminders as iCalendar (.ics) files for Google Calendar, Apple Calendar, and Outlook
- Browser notifications support for scheduled booking alerts

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Smart-booking-reminder.git
   cd Smart-booking-reminder
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `Smart Booking Reminder Automation (1).html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/Smart Booking Reminder Automation (1).html](http://localhost:8000/Smart Booking Reminder Automation (1).html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for Smart Booking Reminder Automation.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.

## Environment Variables

None required. All data persists locally in the browser.
